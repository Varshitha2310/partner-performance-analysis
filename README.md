# Partner & Channel Performance Analysis

Analyses the performance of 15 simulated recruitment-advertising partners (job boards, aggregators,
niche boards, social, campus and regional portals) across 3 regions over 6 months, and recommends
where to scale, optimise or pause spend.

> **Data note:** The dataset is synthetic, generated by `generate_data.py`, to mimic partner/publisher
> performance data. Findings illustrate the method, not real-world benchmarks.

## Business questions
1. Which partners deliver applies most cost-efficiently?
2. Does the cheapest partner also deliver the best hiring outcomes?
3. How much spend sits with underperforming partners?

## Method
- KPIs: CPC, apply rate, cost per apply, cost per hire
- Segmentation vs median benchmarks: **Scale** / **Optimize** / **Review-Pause**
- Views: by partner, partner type, region, and month

## Key insights
- Social partners are the most expensive per hire (about 20x niche boards) despite looking affordable per click.
- Niche boards cost more per apply but have the lowest cost per hire, so judging on cost per apply alone misleads.
- Four partners flagged Review/Pause hold about 24% of spend, which is the budget reallocation opportunity.

## Run
```bash
pip install -r requirements.txt
python generate_data.py
python analysis.py
```
Outputs: `charts/` (3 PNGs), `data/partner_summary.csv`, and console insights.
